# 🔧 Installation

Taurus Vision is distributed as a compiled MetaTrader Expert Advisor.

### MetaTrader 5

1. Download the `.ex5` file.
2. Open MetaTrader 5.
3. Go to **File → Open Data Folder**.
4. Open `MQL5 → Experts`.
5. Copy the `.ex5` file into the `Experts` folder.
6. Restart MetaTrader 5 or refresh Expert Advisors in Navigator.
7. Attach Taurus Vision to any chart.

### MetaTrader 4

1. Download the `.ex4` file.
2. Open MetaTrader 4.
3. Go to **File → Open Data Folder**.
4. Open `MQL4 → Experts`.
5. Copy the `.ex4` file into the `Experts` folder.
6. Restart MetaTrader 4 or refresh Expert Advisors in Navigator.
7. Attach Taurus Vision to any chart.

> **Important:** Taurus Vision is an Expert Advisor. Place the file inside the `Experts` folder, not the `Indicators` folder.
